# Pegoles 2.0 interface preview

The 2.0 series is being integrated. The published source installation in
the README still selects **v0.1.0**; these screenshots do not announce a
2.0 release or change its hardware acceptance status.

## What's in the preview

- **Animated presence:** the agent avatar reflects states such as idle,
  thinking, working and needing your attention.
- **Personalization:** choose a name, shape, color and expression in
  Settings → Appearance preferences → Make your agent.
- **Two interface languages:** English and português (Brasil), selected
  in the same dialog. Changing appearance or language does not change
  the agent's safety rules.
- **Experimental team progress:** captain, researcher, executor and
  critic roles show short status notes. These are progress summaries,
  not hidden model reasoning. Team mode is optional, uses Anthropic,
  requires native confirmation and does not run on Pegoles Local.

The series also includes guest snapshot controls, input approvals and
local task results/history. The screenshots below do not validate their
native behavior. See [the implementation series](https://github.com/zezortdx/Pegoles-Agent/blob/a10287869c515152428657b8368da993a3b2026c/docs/superpowers/plans/2026-10-23-agent-2.0-series.md),
[project state](PROJECT_STATE.md) and [release gates](RELEASE_GATES.md)
for scope and acceptance evidence.

To reproduce after checking out the corresponding frontend source:

```bash

pnpm --filter @pegoles/desktop dev
```

Open `http://localhost:1430/#/dev/shell/home` in a browser and follow the
table. These routes exist only in development; they are excluded from the
production bundle. Avoid using them as hardware E2E or release evidence.
