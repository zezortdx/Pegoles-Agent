## Verification

- `bash scripts/check.sh` green on every branch (Rust 1.97.1, pnpm 9.15.9;
  run with `RUST_TEST_THREADS=1`).
- Not run: Apple silicon hardware acceptance, native macOS prompts, and any
  cloud inference. `docs/RELEASE_GATES.md` lists the manual steps.

## Risks

- PR 4 to PR 6 change security boundaries (approvals, human input, cloud
  team mode); each updated `THREAT_MODEL.md` and `RELEASE_GATES.md`, but
  they need a hardware pass before a release.
- Team mode is weak with the local 2B planner by design and refuses it.
- Takeover button keeps the existing label "Give control to Pegoles".
